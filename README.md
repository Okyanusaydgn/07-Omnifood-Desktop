# ![favicon](https://github.com/user-attachments/assets/2615c722-5b4b-4cb2-bce6-e621237f3120) Omnifood Project 

**Omnifood** is a modern, AI-powered website for personalized, eco-friendly meal plans. Built with a fully responsive design using HTML, CSS, and JavaScript, this project aims to help users create healthy and tailored meal plans. 🌱🤖

## 📌 About the Project

Omnifood is a web application designed to assist users in creating personalized and healthy meal plans. The project features a clean, modern, and responsive design, ensuring a seamless experience across all devices.
